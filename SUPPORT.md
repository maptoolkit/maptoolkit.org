# Getting Support

Thanks for using **Maptoolkit.org**! Here's how to get help.

## 💬 Questions & Support → GitHub Discussions

**Please use [GitHub Discussions](https://github.com/maptoolkit/maptoolkit.org/discussions) for anything support-related.**

That includes:

- "How do I…?" questions
- Integration help (MapLibre, Leaflet, OpenLayers, frameworks, mobile SDKs)
- Style, attribution and license questions
- Performance or caching questions
- Feature ideas and feedback
- Showing off what you built

Before posting, please search existing discussions — your question may already have an answer.

[![GitHub Discussions](https://img.shields.io/badge/GitHub-Discussions-181717?style=for-the-badge&logo=github)](https://github.com/maptoolkit/maptoolkit.org/discussions)

## 🐞 Bug Reports → GitHub Issues

**Issues are reserved for verified code bugs only.** Open an Issue if — and only if — you can demonstrate:

- A clear, reproducible problem in this repository's code or content, **and**
- Concrete steps to reproduce (URL, browser, console output, minimal example), **and**
- The expected vs. actual behaviour.

If you're not sure whether something is a bug, **open a Discussion first**. We'll convert it into an Issue if it turns out to be one. This keeps the issue tracker focused and actionable.

Issues that are actually support questions will be converted to Discussions or closed.

## 🔒 Security Issues

Please **do not** report security vulnerabilities through public Issues or Discussions.
Contact us privately instead — see the repository's security advisories or reach out via the contact details on [maptoolkit.com](https://maptoolkit.com/).
